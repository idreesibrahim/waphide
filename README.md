# WAPHIDE - WhatsApp Web Privacy Extension
**Designed by IDREESIB**

WAPHIDE is a feature-packed Chrome extension for WhatsApp Web that enhances privacy by blurring profile pictures, last message previews, message bodies, and media content.

## Features
- **Profile Pictures Blur:** Hides all profile pictures in chat lists and chat headers.
- **Last Message Previews:** Blurs recent message previews in the side chat list.
- **All Messages in Chat:** Blurs text in active chat conversations.
- **Media Previews:** Hides images, videos, stickers, and voice waveform graphics.
- **Per-Chat Visibility Toggle:** Click the lock/eye icon next to any chat name to keep it visible while hiding others.
- **Quick Keyboard Shortcut:** Press `Alt + X` to quickly turn privacy mode on or off.

## How to Install
1. Extract `WAPHIDE.zip` to a folder on your computer.
2. Open Google Chrome and navigate to `chrome://extensions/`.
3. Enable **Developer mode** in the top right corner.
4. Click **Load unpacked** and select the extracted `WAPHIDE` directory.
5. Open [web.whatsapp.com](https://web.whatsapp.com/) and enjoy complete privacy control!
